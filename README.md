# 💻 Kritika Rana — Developer Portfolio

Welcome to my personal developer portfolio built using **React.js**!  
This responsive website highlights my **skills, projects, certifications**, and **contact info** — with a sleek, dark-themed UI and interactive animations.

---

## 🚀 Tech Stack

- **React.js** – Frontend Framework
- **CSS** – Custom styling and animations
- **JavaScript** – Core logic and interactivity
- **React Icons** – Platform icons (LinkedIn, GitHub, etc.)
- **EmailJS** – Contact form integration (optional)
- **Vite** – Lightning-fast development server
- **Netlify / Vercel** – Deployment platforms

---

## 🧠 Features

- 🔹 **Responsive Design**: Seamless experience on desktop and mobile
- 🔹 **Navbar**: Smooth-scroll links to each section
- 🔹 **Animated UI**: Typewriter effect, icon hover animations, glowing background
- 🔹 **Project Section**: Interactive cards linked to GitHub repositories
- 🔹 **Certifications Section**: Visual grid of certificates with issuers, dates & links
- 🔹 **Contact Section**: Social icons and direct contact info
- 🔹 **Download Resume** button
